#### Теоретический фундамент и архитектура

- **Клиентская часть (`Frontend`):**
    
    - Это часть системы, с которой пользователь взаимодействует напрямую через браузер или мобильное приложение [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding). В классическом вебе она держится на «трех китах»: `HTML` отвечает за структуру (заголовки, формы), `CSS` за внешний вид (цвета, адаптивность через `Tailwind CSS`), а `JavaScript` за поведение (клики, валидация) [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding).
    - Код `Frontend` выполняется непосредственно на устройстве пользователя ('Client-side Execution'), что позволяет интерфейсу быть быстрым и интерактивным [Getting Started: Server and Client Components | Next.js](https://nextjs.org/docs/app/getting-started/server-and-client-components), [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding). Современные 'Client Components' в `Next.js` используют 'Hydration' — процесс привязки обработчиков событий к статичному `HTML` для оживления интерфейса [Getting Started: Server and Client Components | Next.js](https://nextjs.org/docs/app/getting-started/server-and-client-components).
- **Серверная часть (`Backend`):**
    
    - Отвечает за обработку данных, «тяжелую» бизнес-логику ('Business Logic'), авторизацию и общение с внешними сервисами [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding). 'Backend' — это программное обеспечение, работающее на сервере (физической или виртуальной машине в облаке), которое принимает запросы от клиента и возвращает ответы [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding).
    - Взаимодействие происходит по протоколам `HTTP/HTTPS`, которые определяют правила обмена данными через сеть [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding), [Pro Git](https://progit.pdf/). Использование `HTTPS` критично для шифрования передаваемого контента [Pro Git](https://progit.pdf/).
- **Базы данных (`Database`):**
    
    - Предназначены для надежного хранения состояний системы: учетных записей пользователей, логов, заказов и контента [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding), [Build a User Management App with Next.js | Supabase Docs](https://supabase.com/docs/guides/getting-started/tutorials/with-nextjs).
    - **Реляционные базы** (`PostgreSQL`, `SQLite`) организуют данные в виде таблиц и связей, используя язык `SQL` [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding), [Clean Architecture](https://Clean Architecture A Craftsman Guide to Software Structure and Design.pdf).
    - **BaaS** (`Supabase`) предоставляет готовую инфраструктуру: базу данных, аутентификацию и хранилище файлов, доступные через `API`, что избавляет разработчика от настройки серверов вручную [Build a User Management App with Next.js | Supabase Docs](https://supabase.com/docs/guides/getting-started/tutorials/with-nextjs), [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding).
    - **NoSQL/Vector** решения (например, `Qdrant`) используются для специфических задач, таких как семантический поиск по 'Embeddings' [Overview - Qdrant](https://qdrant.tech/documentation/overview), [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding).
- **`API` и формат `JSON`:**
    
    - `API` (Application Programming Interface) — это интерфейс-договор между программами. Он определяет, куда отправить запрос и какой ответ ожидать [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding), [Vibe Coding - Building Production-Grade Software](https://bibis.ir.pdf/).
    - `JSON` (JavaScript Object Notation) — универсальный текстовый формат обмена данными, представляющий собой иерархическую структуру «ключ-значение» [Vibe Coding - Building Production-Grade Software](https://bibis.ir.pdf/), [Clean Architecture](https://Clean Architecture A Craftsman Guide to Software Structure and Design.pdf).

**Пример асинхронного `fetch`-запроса на `JavaScript`:**

```js
async function getUserData() {
  const response = await fetch('https://api.example.com/v1/user/profile');
  const data = await response.json(); // Преобразование ответа в JSON-объект
  console.log(data.user.name);
}
```

[Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding), [CLI Reference | Supabase Docs](https://supabase.com/docs/reference/cli).

```
// Обработка входящего JSON-пакета
export async function POST(request) {
  const body = await request.json(); // Получение JSON-данных из тела запроса

  return new Response(JSON.stringify({ success: true, message: "Logged in" }), {
```

#### Глоссарий терминов

- **Frontend & Client-side Execution** — выполнение программного кода в браузере пользователя для обеспечения интерактивности интерфейса [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding), [Getting Started: Server and Client Components | Next.js](https://nextjs.org/docs/app/getting-started/server-and-client-components).
- **Backend & Business Logic** — серверная логика приложения, отвечающая за безопасность, обработку данных и интеграцию с внешними `API` [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding).
- **Database (`PostgreSQL` / `Supabase`)** — системы для постоянного хранения информации, от классических реляционных таблиц до современных облачных `BaaS` решений [Build a User Management App with Next.js | Supabase Docs](https://supabase.com/docs/guides/getting-started/tutorials/with-nextjs), [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding).
- **REST API & HTTP Methods (`GET`/`POST`)** — стандарт взаимодействия между системами, где `GET` используется для получения данных, а `POST` — для их отправки или создания [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding), [Pro Git](https://progit.pdf/).
- **JSON Payload Structure** — формат данных, используемый для передачи структурированной информации в теле 'HTTP'-запроса или ответа [Vibe Coding - Building Production-Grade Software](https://bibis.ir.pdf/).

#### Практический кейс: Жизненный цикл запроса при авторизации

Разберем путь данных при входе пользователя в систему:

1. **Событие в `React`:** Пользователь нажимает кнопку «Войти». 'Client Component' перехватывает событие 'onClick' [Getting Started: Server and Client Components | Next.js](https://nextjs.org/docs/app/getting-started/server-and-client-components).
2. **Формирование `JSON`:** Данные из полей ввода упаковываются в `JSON`-объект `{"email": "...", "password": "..."}` [Vibe Coding - Building Production-Grade Software](https://bibis.ir.pdf/).
3. **Передача через `API`:** Функция `fetch` отправляет 'POST'-запрос на 'Backend' эндпоинт (например, `/api/login`) [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding).
4. **Обработка на `Backend`:** Сервер принимает запрос, извлекает данные и обращается к `Database` (`Supabase`), чтобы найти пользователя с таким email [Build a User Management App with Next.js | Supabase Docs](https://supabase.com/docs/guides/getting-started/tutorials/with-nextjs).
5. **Проверка в `Database`:** База данных проверяет наличие записи и возвращает результат. Если пароль верен, сервер формирует успешный `JSON`-ответ с токеном сессии [Build a User Management App with Next.js | Supabase Docs](https://supabase.com/docs/guides/getting-started/tutorials/with-nextjs).
6. **Ответ:** Браузер получает ответ, обновляет состояние интерфейса и перенаправляет пользователя в личный кабинет [Build a User Management App with Next.js | Supabase Docs](https://supabase.com/docs/guides/getting-started/tutorials/with-nextjs).
