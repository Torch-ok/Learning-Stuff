#### Сквозной практический кейс: Проектирование полного стека и архитектурных связей для сервиса онлайн-бронирования

**Постановка задачи:** Разработка архитектуры `MVP` сервиса для бронирования рабочих мест в коворкинге. Система должна позволять пользователю выбирать дату, видеть доступные места и создавать заявку на бронирование [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding).

**Пошаговый алгоритм решения:**

1. **Определение требований к `Frontend`:** Интерфейс реализуется на `React` с использованием `Client Components` для интерактивной карты мест и обработки событий клика (`onClick`). Стилизация выполняется через `Tailwind CSS` для обеспечения адаптивности на мобильных устройствах [Getting Started: Server and Client Components | Next.js](https://nextjs.org/docs/app/getting-started/server-and-client-components), [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding).
2. **Проектирование `Backend` и эндпоинтов:** Серверная логика должна проверять доступность места на конкретное время и предотвращать конфликт «двойного бронирования». Создаются эндпоинты: `GET /api/spaces` для получения списка мест и `POST /api/bookings` для создания новой записи [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding), [Clean Architecture](https://Clean Architecture A Craftsman Guide to Software Structure and Design.pdf).
3. **Проектирование схемы `Database`:** В `Supabase` создаются таблицы `profiles` (данные пользователей) и `bookings` (связи между пользователем, местом и временем). Обязательно настраивается `Row Level Security (RLS)`, чтобы пользователи могли видеть только свои бронирования [Build a User Management App with Next.js | Supabase Docs](https://supabase.com/docs/guides/getting-started/tutorials/with-nextjs).
4. **Составление спецификации `JSON`:** Структура передачи данных для нового бронирования должна быть строгой и содержать необходимые `ID`:
    
    ```
    {
      "space_id": "uuid_456",
      "booking_date": "2026-08-10",
      "start_time": "10:00",
      "end_time": "18:00"
    }
    ```
    
    [Vibe Coding - Building Production-Grade Software](https://bibis.ir.pdf/).
5. **Распределение ролей:** Человек-архитектор задает структуру базы данных и правила безопасности (`RLS`). ИИ-агент (`Claude Code` или `Cursor`) генерирует код компонентов, `API`-маршруты и пишет `Unit`-тесты для проверки логики перекрытия времени бронирований [Vibe Coding - Building Production-Grade Software](https://bibis.ir.pdf/), [Build a User Management App with Next.js | Supabase Docs](https://supabase.com/docs/guides/getting-started/tutorials/with-nextjs).
