
#### Теоретический фундамент и архитектура

- **Перевод текста в математическое представление (`Embeddings`):**
    
    - `Embeddings` — это технология преобразования абстрактных данных (текста, кода, изображений) в набор чисел или `Dense Vector` фиксированной длины, который отражает семантическую суть или "концептуальное ядро" объекта [Вайбкодинг 101: полный гайд для новичков в 2026 году](https://vibecoding.ru/vibecoding), [Overview - Qdrant](https://qdrant.tech/documentation/overview), [Эмбеддинги для начинающих / Хабр](https://habr.com/ru/companies/otus/articles/787116). В отличие от простого текста, компьютер работает с этими числами для выполнения математических операций над смыслами [Эмбеддинги для начинающих / Хабр](https://habr.com/ru/companies/otus/articles/787116).
    - Тексты любой длины преобразуются в векторы фиксированной размерности (например, 1536 или 3072 измерения), что позволяет единообразно сравнивать короткие фразы и целые абзацы документации [Vector embeddings | OpenAI API](https://developers.openai.com/api/docs/guides/embeddings), [Эмбеддинги для начинающих / Хабр](https://habr.com/ru/companies/otus/articles/787116).
- **Концепция Семантического пространства (`Vector Space`):**
    
    - `Vector Space` — это многомерная математическая структура, в которой каждый вектор представляет собой точку. Пространственная организация устроена так, что объекты с похожим смыслом располагаются в ней близко друг к другу [Overview - Qdrant](https://qdrant.tech/documentation/overview), [Эмбеддинги для начинающих / Хабр](https://habr.com/ru/companies/otus/articles/787116).
    - **Принцип кластеризации:** В таком пространстве слова «кошка» и «котенок» будут находиться ближе, чем «кошка» и «окошко», а технические фразы "ошибка авторизации" и "invalid credentials" окажутся семантическими соседями, так как модель обучена понимать контекст их использования [Эмбеддинги для начинающих / Хабр](https://habr.com/ru/companies/otus/articles/787116), [Overview - Qdrant](https://qdrant.tech/documentation/overview). Это позволяет группировать данные по сходству (`Clustering`) и обнаруживать скрытые связи в базе знаний проекта [Vector embeddings | OpenAI API](https://developers.openai.com/api/docs/guides/embeddings).
- **Математическая метрика сходства — Косинусное сходство (`Cosine Similarity`):**
    
    - Для определения близости двух смыслов используется `Cosine Similarity`, которая измеряет косинус угла между векторами в пространстве. Если угол мал, косинус близок к 1, что означает высокую семантическую релевантность [Эмбеддинги для начинающих / Хабр](https://habr.com/ru/companies/otus/articles/787116), [Vector embeddings | OpenAI API](https://developers.openai.com/api/docs/guides/embeddings).
    - В этом заключается главное отличие `Semantic Search` от традиционного `Keyword Search`: семантический поиск найдет документы про "глобальное потепление" по запросу "изменение климата", даже если в них нет ни одного совпадающего слова, благодаря их близости в векторном пространстве [Overview - Qdrant](https://qdrant.tech/documentation/overview), [Vector embeddings | OpenAI API](https://developers.openai.com/api/docs/guides/embeddings).

#### Практическая реализация и синтаксис

**Пример вычисления `Cosine Similarity` на Python:**

```python
import numpy as np

def cosine_similarity(v1, v2):
    # Вычисление косинусного сходства через скалярное произведение норм
    return np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))

# Векторы нормализованы к длине 1, поэтому можно использовать просто dot product
v_query = np.array([0.12, -0.05, ...])
v_doc = np.array([0.11, -0.04, ...])
print(f"Similarity score: {np.dot(v_query, v_doc)}")
```

1. **Preprocessing:** Вся документация разбивается на фрагменты (чанки) и для каждого через API (например, `text-embedding-3-small`) генерируется вектор [Vector embeddings | OpenAI API](https://developers.openai.com/api/docs/guides/embeddings).
2. **Storage:** Векторы сохраняются в векторную базу данных (например, `Qdrant` или `Supabase pgvector`) вместе с метаданными [Overview - Qdrant](https://qdrant.tech/documentation/overview), [Build a User Management App with Next.js | Supabase Docs](https://supabase.com/docs/guides/getting-started/tutorials/with-nextjs).
3. **Search:** Когда пользователь вводит запрос "Как сбросить пароль?", запрос также переводится в вектор. Система ищет в базе данных `Top-K` векторов с наибольшим `Cosine Similarity` [Overview - Qdrant](https://qdrant.tech/documentation/overview), [Vector embeddings | OpenAI API](https://developers.openai.com/api/docs/guides/embeddings).
4. **Result:** Пользователь получает статью "Инструкция по восстановлению доступа", так как эти концепции находятся в одной области `Vector Space`, хотя слова "сбросить" и "восстановление" различны [Overview - Qdrant](https://qdrant.tech/documentation/overview).
