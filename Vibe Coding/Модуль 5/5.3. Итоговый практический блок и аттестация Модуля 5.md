#### Сквозной практический кейс: Полный цикл публикации (Deploy Workflow) MVP приложения

**Постановка задачи:** Развернутое на `Vercel` приложение для учета задач падает с ошибкой сборки на этапе `Build Step`. После исправления сборки клиентская часть не может получить данные из `Supabase` из-за блокировки `CORS Policy` [Вайбкодинг 101](https://vibecoding.ru/vibecoding), [Vibe Coding Guide](https://bibis.ir.pdf/).

**Пошаговый алгоритм решения:**

1. **Настройка автодеплоя:** Разработчик авторизуется на `Vercel` через `GitHub` и импортирует репозиторий `first-vibe-project`. Выбирается пресет `Next.js`, который автоматически настраивает команды `Build` и `Output Directory` [Вайбкодинг 101](https://vibecoding.ru/vibecoding), [Next.js Docs](https://nextjs.org/docs/app/getting-started/project-structure).
2. **Конфигурация переменных окружения:** В панели управления `Vercel` (раздел `Environment Variables`) вручную прописываются ключи `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`. Это позволяет приложению работать в облаке, не раскрывая секреты в публичном `GitHub` репозитории [Use Supabase with Next.js](https://supabase.com/docs/guides/getting-started/quickstarts/nextjs), [Next.js Docs](https://nextjs.org/docs/app/getting-started/project-structure).
3. **Исправление `Build Errors`:** ИИ-агент анализирует логи `Vercel` и выявляет ошибки типизации в серверных компонентах. После выполнения локальной проверки `pnpm build` и фиксации правок через `git commit`, изменения пушатся в `main`, инициируя повторную сборку [Vibe Coding Guide](https://bibis.ir.pdf/), [Next.js Docs](https://nextjs.org/docs/app/getting-started/server-and-client-components).
4. **Настройка CORS и домена:** Для устранения блокировки запросов в настройках `Supabase Dashboard` обновляется параметр `auth.site_url`, куда вносится новый адрес приложения от `Vercel`. При необходимости привязывается кастомный домен, для которого `Vercel` автоматически генерирует `SSL`-сертификат [Supabase CLI config](https://supabase.com/docs/guides/local-development/cli/config), [Вайбкодинг 101](https://vibecoding.ru/vibecoding).

#### Комплексный контрольный тест для самопроверки

1. **Анализ платформ**: Сравните `Vercel` и `Netlify` для деплоя `Next.js` приложения. Почему в 2026 году для вайбкодера `Vercel` является более "дружелюбным" решением с точки зрения минимизации настройки инфраструктуры? [Вайбкодинг 101](https://vibecoding.ru/vibecoding), [Vibe Coding Guide](https://bibis.ir.pdf/).
2. **Диагностика CORS**: Объясните, почему ошибка `Access to fetch at... has been blocked by CORS policy` чаще всего возникает именно после деплоя, хотя в локальной разработке (`localhost`) все работало корректно. Как это связано с защитными механизмами браузера? [Vibe Coding Guide](https://bibis.ir.pdf/), [Вайбкодинг 101](https://vibecoding.ru/vibecoding).
3. **Практика по Env Vars**: Составьте инструкцию для ИИ-агента, как правильно подготовить файл `.env.example`, чтобы коллега мог развернуть проект, не зная ваших личных `API`-ключей, но понимая, какие данные нужно получить от `OpenAI` и `Supabase` [Use Supabase with Next.js](https://supabase.com/docs/guides/getting-started/quickstarts/nextjs), [Next.js Docs](https://nextjs.org/docs/app/getting-started/project-structure).
4. **Процесс CI/CD**: Опишите жизненный цикл изменения кода от момента ввода команды `git push` до появления новой фичи на живом сайте. Какие этапы (`Lint`, `Build`, `Deploy`) проходят в автоматическом режиме? [Вайбкодинг 101](https://vibecoding.ru/vibecoding), [Vibe Coding Guide](https://bibis.ir.pdf/).
5. **Pre-deploy Checklist**: Сформируйте список из 5 обязательных проверок перед публикацией `MVP` в продакшн, включая проверку `.gitignore` на предмет секретов и запуск финальных `Smoke Tests` [Vibe Coding Guide](https://bibis.ir.pdf/), [Next.js Docs](https://nextjs.org/docs/app/getting-started/project-structure).
