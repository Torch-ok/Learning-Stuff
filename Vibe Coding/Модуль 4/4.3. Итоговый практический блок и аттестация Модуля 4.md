#### Сквозной практический кейс: Алгоритм вывода ИИ из циклической ошибки (Infinite Bug Loop) при дебаггинге

**Постановка задачи:** В процессе разработки Fullstack-приложения возникла ошибка `CORS` при взаимодействии `Frontend` на `Next.js` и `Backend` эндпоинта. После нескольких попыток исправления ИИ начал предлагать одни и те же неработающие заголовки, одновременно ломая логику авторизации [Vibe Coding Guide](https://bibis.ir.pdf/).

**Пошаговый алгоритм решения:**

1. **Сбор диагностических данных:** Разработчик извлекает полный `StackTrace` серверной ошибки и детальный лог из `Network Tab` браузера. Важно передать ИИ не описание «не работает», а фактический текст ошибки: `Access to fetch at ... has been blocked by CORS policy` [Vibe Coding Guide](https://bibis.ir.pdf/), [Вайбкодинг 101](https://vibecoding.ru/vibecoding).
2. **Фиксация и сброс (`Context Reset`):** Текущие изменения сохраняются в `Git` (`checkpoint`), после чего диалог полностью очищается. Это необходимо, так как при заполнении `Context Window` более чем на 50% модель начинает игнорировать инструкции и «тупеть» [Vibe Coding Guide](https://bibis.ir.pdf/), [Как устроены AI токены / Хабр](https://habr.com/ru/companies/gptunnel/articles/986526/).
3. **Формирование промпта по `RCTO`:** Создается новый запрос.
    - **Role:** `Security & Infrastructure Expert`.
    - **Context:** Файлы `next.config.js`, схема `Middleware` и настройки `Supabase`.
    - **Task:** Сформулировать гипотезу, почему текущие `CORS` настройки конфликтуют с `SSR` авторизацией, и предложить исправление.
    - **Output:** Только код конфигурации с комментариями по каждой строке [Prompt engineering | OpenAI API](https://developers.openai.com/api/docs/guides/prompt-engineering), [Vibe Coding Guide](https://bibis.ir.pdf/).
4. **Валидация:** После применения кода разработчик лично проверяет прохождение запроса. Если ошибка сохраняется, используется техника `Tracer Bullet` — создание простейшего эндпоинта для проверки работоспособности сетевого пути в обход сложной логики [Vibe Coding Guide](https://bibis.ir.pdf/).
