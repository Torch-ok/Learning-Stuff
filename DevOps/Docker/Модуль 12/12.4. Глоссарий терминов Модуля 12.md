## Практическое упражнение (Комплексный Troubleshooting: Восстановление упавшего трехкомпонентного стека)

**Сюжет аварии:** Вы разворачиваете обновленную версию магазина через `docker compose up -d`. Однако пользователи сообщают, что сайт недоступен. Браузер выдает `502 Bad Gateway`. Ваша задача — локализовать и устранить проблему [Docker и Docker Compose - Полный Курс / YouTube](https://www.youtube.com/watch?v=029uHVtpY08).

### Шаг 1: Первичный аудит статусов

Запускаем проверку состояния сервисов:

```bash
docker compose ps
```

**Результат терминала:**

- `gateway` (Nginx): `Up (healthy)`
- `backend` (Flask): `Restarting...`
- `database` (Postgres): `Up (unhealthy)`

### Шаг 2: Анализ логов «нездоровой» БД

Проверяем, почему PostgreSQL пометил себя как `unhealthy`:

```bash
docker compose logs database
```

**Вывод лога:** `FATAL: password authentication failed for user "postgres"`. `DETAIL: Password does not match for the role defined in secrets`. **Диагноз:** Ошибка в конфигурации паролей. Секрет, монтируемый в `/run/secrets/`, не совпадает с переменной, переданной при инициализации тома [Docker Deep Dive](obsidian://open?vault=DevOps&file=Sources%2FDocker%2FPdf%2FDocker%20Deep%20Dive%20Zero%20to%20Docker%20in%20a%20single%20book%20(Nigel%20Poulton)%20(z-lib.org).pdf), [11.3. Менеджмент секретов].

### Шаг 3: Профилирование ресурсов бэкенда

Flask постоянно перезапускается. Проверим ресурсы:

```bash
docker container stats backend
```

**Наблюдение:** Перед падением `MEM USAGE` резко подскакивает до лимита в 128MB. **Диагноз:** Утечка памяти или бесконечный цикл при попытке достучаться до БД, которая не принимает соединения [Docker-Cookbook](https://www.oreilly.com/library/view/docker-cookbook/9781491917565/).

### Шаг 4: Хирургическая проверка через exec

Заходим в БД, чтобы проверить права на файлы данных:

```bash
docker compose exec database ls -la /var/lib/postgresql/data
```

**Результат:** Владелец файлов — `root`, хотя база должна работать от `postgres` (UID 70). Это произошло из-за некорректного Bind Mount на новую папку хоста [Изучаем Docker, часть 6: работа с данными / Хабр](https://habr.com/ru/companies/ruvds/articles/441574/).

### Финальное исправление манифеста

Мы исправляем соответствие паролей, правим права на тома и внедряем строгую зависимость [Docker Fundamentals: теория и базовая эксплуатация / Хабр](https://habr.com/ru/companies/ruvds/articles/1043544/):

```yml
services:
  database:
    # ... (исправленные пароли и volumes)
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 10s
      start_period: 30s # Даем время на исправление прав

  backend:
    # ...
    depends_on:
      database:
        condition: service_healthy # Flask не стартанет, пока БД не ответит OK
```

[Defining start conditions for the container - MOOC.fi](https://courses.mooc.fi/org/uh-cs/courses/devops-with-docker-spring-2026/chapter-2/defining-start-conditions-for-the-container).
