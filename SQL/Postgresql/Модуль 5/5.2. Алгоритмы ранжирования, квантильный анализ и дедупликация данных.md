#### Теоретический фундамент и архитектура

**Назначение и математика ранжирующих оконных функций:** Ранжирование («Ranking») в SQL представляет собой процесс присвоения числового значения строке на основе её позиции в отсортированном наборе данных внутри партиции [Advanced SQL — Video #37](https://notebook.google.com/notebook/3), [Alan_Beaulieu-Learning_SQL-RU.pdf](https://notebook.google.com/notebook/35). В отличие от агрегатных функций, ранжирующие функции всегда требуют наличия блока `ORDER BY` внутри спецификации окна `OVER()`, иначе результат будет не детерминированным [Advanced SQL — Video #37](https://notebook.google.com/notebook/4).

- **Функция `ROW_NUMBER()`:** Генерирует строго последовательные уникальные целые числа, начиная с единицы. Она не учитывает совпадения значений («ties») в колонках сортировки: если две строки имеют одинаковые значения, им все равно будут присвоены разные порядковые номера [Advanced SQL — Video #37](https://notebook.google.com/notebook/3), [SQL. Сборник рецептов, 2-е издание.pdf](https://notebook.google.com/notebook/242).
- **Функция `RANK()`:** Присваивает одинаковый ранг строкам с совпадающими значениями. Однако при этом создается «разрыв» («gap») в последовательности последующих номеров. Например, если две строки делят первое место, следующей строке будет присвоен ранг 3 [Advanced SQL — Video #37](https://notebook.google.com/notebook/3), [Alan_Beaulieu-Learning_SQL-RU.pdf](https://notebook.google.com/notebook/257).
- **Функция `DENSE_RANK()`:** Работает аналогично `RANK()`, присваивая одинаковые значения «сверстникам», но не допускает пропусков в нумерации. После двух строк с рангом 1 следующая строка получит ранг 2 [Advanced SQL — Video #37](https://notebook.google.com/notebook/3), [Alan_Beaulieu-Learning_SQL-RU.pdf](https://notebook.google.com/notebook/249).

**Инструменты статистического и квантильного анализа:** Для более глубокой аналитики PostgreSQL предоставляет функции распределения, которые позволяют смотреть на данные в разных масштабах точности [Advanced SQL — Video #38](https://notebook.google.com/notebook/7).

- **Функция `NTILE(num_buckets)`:** Разбивает отсортированную партицию на указанное количество максимально равных групп (корзин). Это стандартный инструмент для вычисления квартилей (4 группы) или децилей (10 групп). Если общее количество строк не делится нацело, остаток распределяется по первым корзинам [Advanced SQL — Video #38](https://notebook.google.com/notebook/9), [SQL. Сборник рецептов, 2-е издание.pdf](https://notebook.google.com/notebook/314).
- **Относительное ранжирование:**
    - **`PERCENT_RANK()`** — вычисляет относительный ранг строки по формуле $(\text{rank}-1) / (\text{total_rows}-1)$, возвращая значение от 0 до 1 [Advanced SQL — Video #38](https://notebook.google.com/notebook/6).
    - **`CUME_DIST()`** — определяет кумулятивное распределение (долю строк, значения которых меньше или равны текущему) [Advanced SQL — Video #38](https://notebook.google.com/notebook/6), [Advanced SQL — Video #38](https://notebook.google.com/notebook/8).

**Архитектурный паттерн дедупликации (Deduplication Pattern):** Одной из важнейших прикладных задач ранжирования является устранение дубликатов. Паттерн заключается в использовании `ROW_NUMBER()` с партиционированием по полям-дублям и сортировкой по приоритету (например, по дате изменения). Строки с номером больше 1 считаются избыточными и подлежат фильтрации или удалению [SQL. Сборник рецептов, 2-е издание.pdf](https://notebook.google.com/notebook/258), [SQL. Сборник рецептов, 2-е издание.pdf](https://notebook.google.com/notebook/260).

#### Практическая реализация и синтаксис

Пример сравнения трех основных функций ранжирования на результатах тестов:

```
SELECT student_name,
       score,
       ROW_NUMBER() OVER(ORDER BY score DESC) as row_num,
       RANK()       OVER(ORDER BY score DESC) as rank_gap,
       DENSE_RANK() OVER(ORDER BY score DESC) as rank_dense
FROM exam_results;
```

[Advanced SQL — Video #37](https://notebook.google.com/notebook/3), [Alan_Beaulieu-Learning_SQL-RU.pdf](https://notebook.google.com/notebook/250).

**Дедупликация таблицы кликов (оставляем самый свежий клик на пользователя):**

```
WITH RankedClicks AS (
    SELECT click_id, user_id, click_time,
           ROW_NUMBER() OVER(PARTITION BY user_id ORDER BY click_time DESC) as rn
    FROM user_clicks
)
SELECT click_id, user_id, click_time
FROM RankedClicks
WHERE rn = 1;
```

**Сегментация клиентов по объему покупок (RFM-анализ):**

```
SELECT customer_id,
       total_spent,
       -- Разбиение на 4 равные группы (квартили)
       NTILE(4) OVER(ORDER BY total_spent DESC) as spend_quartile
FROM sales_stats;
```

#### Глоссарий терминов

- **Sequential Numbering (`ROW_NUMBER`)** — присвоение уникального целого числа каждой строке в партиции согласно порядку сортировки [Advanced SQL — Video #37](https://notebook.google.com/notebook/3), [SQL. Сборник рецептов, 2-е издание.pdf](https://notebook.google.com/notebook/242).
- **Rank with Gaps (`RANK`)** — алгоритм ранжирования, при котором одинаковые значения получают один номер, а последующий номер пропускается [Advanced SQL — Video #37](https://notebook.google.com/notebook/3), [Alan_Beaulieu-Learning_SQL-RU.pdf](https://notebook.google.com/notebook/257).
- **Dense Ranking (`DENSE_RANK`)** — плотное ранжирование без пропусков в числовой последовательности при наличии одинаковых значений [Advanced SQL — Video #37](https://notebook.google.com/notebook/3), [Alan_Beaulieu-Learning_SQL-RU.pdf](https://notebook.google.com/notebook/249).
- **Quantile Distribution (`NTILE`)** — разделение набора данных на фиксированное количество статистически равных групп [Advanced SQL — Video #38](https://notebook.google.com/notebook/7), [Advanced SQL — Video #38](https://notebook.google.com/notebook/9).
- **Cumulative Distribution (`CUME_DIST`)** — функция, возвращающая относительную позицию значения в наборе данных как долю строк [Advanced SQL — Video #38](https://notebook.google.com/notebook/6).
- **Relative Rank (`PERCENT_RANK`)** — вычисление процентного ранга строки относительно всего набора данных [Advanced SQL — Video #38](https://notebook.google.com/notebook/6).
- **SQL Deduplication Pattern** — метод очистки данных с использованием оконных функций для идентификации и фильтрации повторяющихся записей [SQL. Сборник рецептов, 2-е издание.pdf](https://notebook.google.com/notebook/258).

#### Практический кейс: Построение топа продаж Top-N per Category

**Сценарий:** Необходимо вывести ровно 3 самых дорогих товара для каждой категории. Если несколько товаров имеют одинаковую цену, мы должны использовать детерминированный подход, чтобы в отчет всегда попадало ровно 3 записи [Alan_Beaulieu-Learning_SQL-RU.pdf](https://notebook.google.com/notebook/35), [SQL. Сборник рецептов, 2-е издание.pdf](https://notebook.google.com/notebook/248).

**Решение:** Используем `ROW_NUMBER()`, так как он гарантирует отсутствие дублей в нумерации. В `ORDER BY` добавляем вторичный ключ (например, `product_id`), чтобы обеспечить стабильность результата при совпадении цен [Advanced SQL — Video #37](https://notebook.google.com/notebook/4), [SQL. Сборник рецептов, 2-е издание.pdf](https://notebook.google.com/notebook/250).

```
SELECT category_name, product_name, price
FROM (
    SELECT c.name as category_name,
           p.name as product_name,
           p.price,
           ROW_NUMBER() OVER(PARTITION BY p.category_id
                             ORDER BY p.price DESC, p.product_id ASC) as rn
    FROM products p
    JOIN categories c ON p.category_id = c.category_id
) sub
WHERE rn <= 3;
```

Этот подход позволяет избежать «раздувания» отчета, которое могло бы произойти при использовании `RANK()`, если бы 10 товаров имели одинаковую максимальную цену [Alan_Beaulieu-Learning_SQL-RU.pdf](https://notebook.google.com/notebook/250).
