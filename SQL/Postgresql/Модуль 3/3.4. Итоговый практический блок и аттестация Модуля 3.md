#### Сквозной практический кейс: Расчет продуктовых и финансовых метрик e-commerce (ARPU, AOV, Retention)

**Постановка задачи:** Необходимо сформировать отчет для аналитического отдела e-commerce платформы. Отчет должен включать расчет среднего чека, дохода на пользователя и активности покупателей в разрезе ежемесячных когорт, учитывая только успешно оплаченные заказы [Шилдс Уолтер SQL.pdf](https://notebook.google.com/notebook/466).

**Пошаговый алгоритм выполнения:**

1. **Расчет среднего чека (AOV):** Используем `SUM(amount) / COUNT(*)` с фильтрацией статуса через `FILTER`, чтобы исключить отмененные заказы и защититься от деления на ноль [Шилдс Уолтер SQL.pdf](https://notebook.google.com/notebook/503).
    
    ```
    SELECT
        SUM(total_amount) FILTER (WHERE status = 'PAID') /
        NULLIF(COUNT(*) FILTER (WHERE status = 'PAID'), 0) AS average_order_value
    FROM orders;
    ```
    
2. **Расчет дохода на одного активного пользователя (ARPU):** Применяем `COUNT(DISTINCT user_id)` для подсчета только уникальных покупателей, совершивших транзакции в отчетном периоде [Alan_Beaulieu-Learning_SQL-RU.pdf](https://notebook.google.com/notebook/40).
    
    ```
    SELECT
        SUM(amount) / COUNT(DISTINCT user_id) AS arpu
    FROM payments
    WHERE payment_date >= '2026-01-01';
    ```
    
3. **Определение доли повторных покупок (Retention Rate):** Используем `GROUP BY` по пользователям и `CASE WHEN` для идентификации тех, кто совершил более одной покупки [Alan_Beaulieu-Learning_SQL-RU.pdf](https://notebook.google.com/notebook/155).
    
    ```
    SELECT
        COUNT(*) FILTER (WHERE order_count > 1) * 100.0 / COUNT(*) AS retention_rate
    FROM (
        SELECT user_id, COUNT(order_id) as order_count
        FROM orders
        GROUP BY user_id
    ) user_stats;
    ```
    
4. **Единый дашборд помесячных когорт:** Собираем метрики в один запрос, используя `EXTRACT` для формирования временных интервалов [SQL. Сборник рецептов, 2-е издание.pdf](https://notebook.google.com/notebook/148).
    
    ```
    SELECT
        EXTRACT(MONTH FROM created_at) AS cohort_month,
        AVG(total_amount) AS aov,
        SUM(total_amount) / COUNT(DISTINCT user_id) AS arpu
    FROM orders
    WHERE status = 'PAID'
    GROUP BY cohort_month
    ORDER BY cohort_month;
    ```
