#### Сквозной практический кейс: Проектирование REST API маршрутизатора для сервиса заказов

**Постановка задачи:** Реализовать модуль `orders.py` для обработки заказов, который включает создание заказа, получение списка с фильтрацией и загрузку сопутствующих документов.

**Пошаговый алгоритм выполнения:**

1. **Инициализация роутера:** Создаем `APIRouter` с базовым префиксом и тегами для группировки в Swagger UI.
    
    ```
    from fastapi import APIRouter, Depends, Header, Body, UploadFile, File, Query
    from typing import Annotated
    from pydantic import BaseModel
    
    router = APIRouter(prefix="/api/v1/orders", tags=["Orders"])
    ```
    
2. **Создание заказа (JSON + Header):** Используем `Body(embed=True)` для четкой структуры JSON и извлекаем ID пользователя из заголовка.
    
    ```
    class OrderSchema(BaseModel):
        item_id: int
        quantity: int
    
    @router.post("/", status_code=201)
    async def create_order(
        order: Annotated[OrderSchema, Body(embed=True)],
        x_user_id: Annotated[int, Header()]
    ):
        return {"user_id": x_user_id, "order": order, "status": "created"}
    ```
    
3. **Получение списка с пагинацией и фильтрами:** Реализуем параметры `limit`, `skip` и поиск по диапазону дат.
    
    ```
    @router.get("/")
    async def get_orders(
        skip: int = 0,
        limit: Annotated[int, Query(le=100)] = 10,
        status: str | None = None
    ):
        return {"skip": skip, "limit": limit, "status_filter": status}
    ```
    
4. **Загрузка чека (UploadFile):** Реализуем асинхронный прием файла с проверкой типа.
    
    ```
    @router.post("/{order_id}/receipt")
    async def upload_receipt(order_id: int, file: UploadFile = File(...)):
        # Валидация через метаданные UploadFile
        if file.content_type != "application/pdf":
            return {"error": "Only PDF allowed"}
    
        # Потоковое чтение
        content = await file.read(1024 * 1024) # читаем чанк 1МБ
        return {"filename": file.filename, "order_id": order_id}
    ```
    
5. **Генерация документации:** После подключения роутера в `main.py` через `app.include_router(orders.router)`, все эндпоинты, их типы и ограничения (например, `le=100` для лимита) автоматически появятся в Swagger UI по адресу `/docs`.
    

#### Комплексный контрольный тест для самопроверки

1. **Вопрос:** В каких случаях FastAPI автоматически возвращает HTTP 422?
    
    - A) Когда ресурс не найден в базе данных.
    - B) При отсутствии обязательного параметра `Header` или `Query`.
    - C) Когда тип данных параметра в URL не совпадает с аннотацией (например, передана строка вместо `int`).
    - D) Когда клиент отправляет JSON, не соответствующий схеме Pydantic.
    - _Ответ: B, C, D._
2. **Задача на архитектуру:** Вы объявили два роутера в `main.py` с одинаковым префиксом `/items`. Один содержит путь `/all`, другой — `/{id}`. Как FastAPI будет обрабатывать запросы и на что нужно обратить внимание при их включении (`app.include_router`)?.
    
3. **Практическое задание:** Напишите аннотацию для параметра заголовка `X-Order-Token`, который должен иметь минимальную длину 16 символов и соответствовать регулярному выражению `^[A-Z0-9]*$`. Используйте `Annotated` и `Header`.
    
4. **Задача на оптимизацию:** Почему чтение файла через `while content := await file.read(chunk_size):` внутри эндпоинта с `UploadFile` является более предпочтительным для систем под высокой нагрузкой, чем использование `file.file.read()`?.
    
5. **Вопрос на совмещение:** Можно ли в одном эндпоинте одновременно объявить параметр из `Path`, параметр из `Form` и параметр из `Body` (JSON)?
    
    - _Ответ: Нельзя совмещать `Form` и `Body` (JSON), так как это требует разных типов кодировки тела запроса (`application/x-www-form-urlencoded` vs `application/json`), что противоречит протоколу HTTP. Параметры `Path` и `Query` могут сочетаться с любым из них._
