#### Теоретический фундамент и архитектура

В FastAPI извлечение данных из HTTP-запроса реализовано через декларативное описание параметров функции-обработчика. Источники данных четко разграничены: параметры пути (`Path`) являются частью URL, параметры запроса (`Query`) передаются после знака вопроса, а заголовки (`Header`) и куки (`Cookie`) извлекаются из соответствующих метаданных пакета.

Механизм автоматической конвертации типов базируется на Pydantic и стандартных аннотациях Python. Если параметр объявлен как `int`, `UUID` или `datetime`, FastAPI автоматически попытается преобразовать строковое значение из запроса в указанный тип. При передаче булевых значений поддерживаются различные варианты написания (`true`, `1`, `on`, `yes`), которые приводятся к `bool`. Для параметров с фиксированным набором значений используются стандартные Python `Enum`, что обеспечивает строгую типизацию и нативную поддержку в документации.

Стандартом разработки в 2026 году является использование `typing.Annotated`. Этот подход позволяет отделить определение типа данных от метаданных валидации, что делает код чище и упрощает работу статических анализаторов (mypy, ruff). В отличие от старого синтаксиса, где классы валидации указывались как значения по умолчанию, `Annotated` позволяет функции оставаться валидной с точки зрения Python даже вне контекста FastAPI.

Для детальной настройки параметров используются классы-сибстеры: `Path`, `Query`, `Header` и `Cookie`, наследуемые от общего базового класса `Param`. Они предоставляют следующие инструменты контроля:

- **Числовая валидация:** ограничения «больше» (`gt`), «больше или равно» (`ge`), «меньше» (`lt`) и «меньше или равно» (`le`).
- **Строковая валидация:** контроль длины (`min_length`, `max_length`) и проверка соответствия регулярным выражениям через параметр `pattern`.
- **Метаданные:** `title`, `description`, `alias` и пометка `deprecated` для автоматической генерации документации OpenAPI.

#### Практическая реализация и синтаксис

Пример современного эндпоинта, объединяющего все типы параметров с использованием `Annotated`:

```python
from uuid import UUID
from datetime import datetime
from typing import Annotated
from fastapi import APIRouter, Path, Query, Header, Cookie

router = APIRouter(prefix="/products", tags=["catalog"])

@router.get("/{product_id}")
async def get_product_details(
    # Параметр пути с валидацией диапазона
    product_id: Annotated[int, Path(title="The ID of the product", ge=1, le=1000)],
    # Параметр запроса с валидацией длины и значением по умолчанию
    search: Annotated[str | None, Query(max_length=50, pattern="^search_.*")] = None,
    # Заголовок с автоматической конвертацией в snake_case (X-Client-Tag -> client_tag)
    x_client_tag: Annotated[str, Header(convert_underscores=True)],
    # Извлечение данных из Cookie
    session_id: Annotated[str | None, Cookie()] = None
):
    return {
        "product_id": product_id,
        "search": search,
        "client_tag": x_client_tag,
        "session": session_id
    }
```

[Header Parameter Models](https://fastapi.tiangolo.com/tutorial/header-param-models/#disable-convert-underscores), [Query Parameters and String Validations](https://fastapi.tiangolo.com/tutorial/query-params-str-validations/#use-annotated-in-the-type-for-the-q-parameter)

> [!warning] Актуализация синтаксиса 
> В старых версиях FastAPI (до 0.95.0) вместо `Annotated` использовалось присвоение `Query(...)` в качестве значения по умолчанию. Этот метод считается устаревшим, так как он заменяет реальное значение по умолчанию объекта, что путает редакторы кода и требует передачи специальных объектов при вызове функции вручную.

#### Глоссарий терминов

- **Path Parameters (`Path`)** — переменные части URL-адреса, используемые для идентификации конкретных ресурсов.
- **Query Parameters (`Query`)** — необязательные параметры, передаваемые в строке запроса для фильтрации или сортировки.
- **Header Parameters (`Header`)** — метаданные запроса, часто используемые для передачи версий API или технических тегов.
- **Cookie Parameters (`Cookie`)** — параметры, извлекаемые из заголовка `Cookie`, передаваемого браузером или клиентом.
- **`typing.Annotated`** — механизм Python для добавления метаданных к типам, рекомендуемый FastAPI для объявления параметров.
- **String Pattern Validation (Regex)** — использование регулярных выражений для строгой проверки формата входных строк.

#### Практический кейс: Построение фильтрации и пагинации каталога товаров

**Сценарий:** Необходимо спроектировать эндпоинт поиска товаров `/api/v1/items/`, который поддерживает фильтрацию по цене, пагинацию (skip/limit), сортировку и отслеживание версии клиента через заголовок.

**Реализация логики:**

1. **Пагинация:** Параметры `skip` и `limit` объявляются как `Query`. Для `limit` устанавливается `le=100`, чтобы предотвратить чрезмерную нагрузку на БД.
2. **Фильтрация:** Диапазон цен реализуется через `min_price` (`ge=0`) и `max_price`.
3. **Сортировка:** Создается `Enum` с вариантами `price_asc`, `price_desc`, что исключает ввод некорректных значений.
4. **Валидация:** При попытке передать отрицательный `limit` или строку в поле цены, FastAPI автоматически сгенерирует ответ **422 Unprocessable Entity**.

**Анализ ответа 422:** JSON-ответ об ошибке содержит поле `loc`, указывающее на источник (например, `["query", "limit"]`), и `msg` с описанием нарушения правила (например, `Input should be less than or equal to 100`). Это позволяет фронтенд-разработчикам мгновенно идентифицировать и исправить ошибку на стороне клиента.

#### Вопросы и задания для самопроверки

1. **Вопрос:** В чем преимущество объявления обязательного параметра запроса без значения по умолчанию по сравнению с использованием `Query(...)` в `Annotated`?
    - _Ответ: `Annotated` позволяет сохранить корректную работу статических анализаторов и IDE, не заставляя Python считать объект `Query` реальным значением переменной._
2. **Задача:** Напишите регулярное выражение для параметра `sku` (артикул), который должен состоять из 3 букв верхнего регистра, дефиса и 4 цифр (например, `ABC-1234`). Интегрируйте его в `Path`.
3. **Практическое задание:** Реализуйте эндпоинт, который извлекает куку `cart_token` и заголовок `X-Request-ID`. Если кука отсутствует, она должна принимать значение по умолчанию `None`, а заголовок должен быть обязательным.
