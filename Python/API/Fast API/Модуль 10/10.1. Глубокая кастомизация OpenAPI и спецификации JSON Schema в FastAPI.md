#### Теоретический фундамент и архитектура

В 2026 году FastAPI остается эталоном среди Python-фреймворков благодаря бесшовной интеграции со спецификацией **OpenAPI (3.1.0)**. Процесс генерации документации полностью автоматизирован: FastAPI анализирует аннотации типов (**Type Hints**), модели Pydantic v2 и декораторы эндпоинтов для сборки итогового файла `openapi.json`. Этот файл служит «единым источником истины» для интерактивных интерфейсов **Swagger UI** (`/docs`) и **ReDoc** (`/redoc`).

**Архитектура сопоставления данных:**

- **Схемы данных**: Модели Pydantic транслируются в секцию `components/schemas` в OpenAPI с использованием стандарта **JSON Schema 2020-12**.
- **Валидация и метаданные**: Инструкции `Field()` в моделях и параметры функций (`Query`, `Path`, `Body`) определяют ограничения (constraints) и описания параметров в итоговой спецификации.
- **Обогащение через Pydantic v2**: Для добавления пользовательских полей в JSON Schema используется атрибут `model_config` с ключом `json_schema_extra`. Начиная с версии 0.99.0, FastAPI поддерживает поле `examples` (список примеров), которое пришло на смену устаревшему одиночному полю `example`.

**Документирование жизненного цикла запроса:** FastAPI позволяет декларативно описывать не только успешные ответы через `response_model`, но и возможные ошибки. Использование параметра `responses` в декораторе пути позволяет добавить в схему подробные описания для статусов 400, 404 или 422, включая структуры JSON-ответов для фронтенд-команд.

#### Практическая реализация и синтаксис

**Настройка Pydantic v2 модели с `json_schema_extra`:**

```
from pydantic import BaseModel, Field, ConfigDict

class Item(BaseModel):
    name: str = Field(..., title="Имя товара", min_length=2)
    price: float = Field(..., gt=0, description="Цена должна быть больше нуля")

    # Современный способ настройки метаданных в Pydantic v2
    model_config = ConfigDict(
        json_schema_extra={
            "examples": [
                {
                    "name": "Portal Gun",
                    "price": 42.0,
                }
            ]
        }
    )
```

[Body - Fields](https://fastapi.tiangolo.com/tutorial/body-fields/), [Declare Request Example Data](https://fastapi.tiangolo.com/tutorial/schema-extra-example/)

**Документирование множественных примеров через `openapi_examples`:** Swagger UI долгое время не поддерживал отображение нескольких примеров из JSON Schema, поэтому FastAPI ввел параметр `openapi_examples` для инструментов `Body`, `Path` и других.

```
from fastapi import Body, status
from typing import Annotated

@app.post("/items/", status_code=status.HTTP_201_CREATED)
async def create_item(
    item: Annotated[
        Item,
        Body(
            openapi_examples={
                "normal": {
                    "summary": "Стандартный товар",
                    "value": {"name": "Laptop", "price": 999.99}
                },
                "invalid": {
                    "summary": "Пример с ошибкой",
                    "value": {"name": "B", "price": -10}
                }
            }
        )
    ]
):
    return item
```

#### Глоссарий терминов

- **[OpenAPI 3.1 Specification](https://fastapi.tiangolo.com/tutorial/first-steps/#openapi)** — современный стандарт описания REST API, обеспечивающий совместимость с JSON Schema 2020-12.
- **[`openapi.json`](https://fastapi.tiangolo.com/tutorial/first-steps/#check-the-openapi-json)** — автоматически генерируемый FastAPI файл манифеста, описывающий все маршруты, модели и требования безопасности приложения.
- **[`json_schema_extra`](https://fastapi.tiangolo.com/tutorial/schema-extra-example/#extra-json-schema-data-in-pydantic-models)** — конфигурационный параметр Pydantic для добавления произвольных данных в генерируемую JSON-схему модели.
- **[Swagger UI & ReDoc](https://fastapi.tiangolo.com/tutorial/first-steps/#interactive-api-docs)** — встроенные инструменты визуализации спецификации OpenAPI для интерактивного тестирования запросов.
- **OpenAPI Customization (`app.openapi()`)** — механизм переопределения базового метода генерации схемы для внесения глобальных правок в спецификацию.
- **[Response Model Documentation (`responses`)](https://fastapi.tiangolo.com/tutorial/bigger-applications/#add-some-custom-tags-responses-and-dependencies)** — параметр декоратора для описания альтернативных HTTP-ответов и их структур.

#### Практический кейс: Проектирование production-ready спецификации API

**Сценарий:** Подготовка документации E-commerce платформы для внешних партнеров. Необходимо скрыть внутренние Health-check эндпоинты, сгруппировать методы по категориям и предоставить примеры для генерации клиентских SDK.

**Реализация:**

1. **Группировка**: Использование параметра `tags` в `APIRouter` и эндпоинтах для создания логических разделов ("Products", "Orders") в Swagger UI.
2. **Скрытие данных**: Для служебных роутов устанавливается `include_in_schema=False`. Это позволяет сохранить работоспособность эндпоинта (например, `/metrics`), но убрать его из публичной документации.
3. **SDK-Friendly**: Явное указание `response_model` гарантирует, что автогенераторы кода создадут корректные классы для ответов, а не будут использовать тип `Any`.
4. **Безопасность**: Настройка `OAuth2PasswordBearer` добавляет кнопку "Authorize", позволяя партнерам тестировать защищенные методы прямо из браузера.

#### Вопросы и задания для самопроверки

1. **Вопрос:** В чем заключается преимущество использования `examples` (список) над `example` (одиночное значение) в OpenAPI 3.1?
    - _Ответ: Поле `examples` соответствует актуальному стандарту JSON Schema и позволяет передавать несколько вариантов данных для тестирования, в то время как `example` признан устаревшим (deprecated)._
2. **Задача:** Как реализовать кэширование схемы `openapi()`?
    - _Подсказка: Проверьте наличие атрибута `app.openapi_schema`. Если он не `None`, возвращайте его, иначе генерируйте схему заново и сохраняйте в этот атрибут._
3. **Практическое задание:** Создайте эндпоинт `/login` и задокументируйте в нем три варианта ответа 400 Bad Request: "Неверный пароль", "Пользователь заблокирован" и "Требуется подтверждение email", используя параметр `responses` и Pydantic-модели.
