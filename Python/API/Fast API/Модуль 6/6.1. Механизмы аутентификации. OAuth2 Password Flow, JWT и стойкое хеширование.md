#### Теоретический фундамент и архитектура

Аутентификация — это фундаментальный процесс проверки личности, отвечающий на вопрос «Кто вы?», в то время как авторизация определяет, какие действия вам разрешены. Идентификация предшествует этим процессам, представляя собой способ заявить о том, кем является субъект (например, через ввод логина). В современной разработке на FastAPI 2026 года стандартом реализации этих механизмов является спецификация **OAuth2**, в частности паттерн **Password Flow** (Resource Owner Password Credentials Grant). Согласно этой схеме, клиент отправляет учетные данные (username и password) в формате `form-data` на сервер авторизации, который после проверки возвращает токен доступа.

FastAPI предоставляет нативные инструменты для интеграции с этим потоком:

- **`OAuth2PasswordBearer`** — это технический компонент (security scheme), который инструктирует FastAPI извлекать токен из заголовка `Authorization` (формат `Bearer <token>`). Его использование автоматически активирует кнопку «Authorize» в интерактивной документации Swagger UI.
- **`OAuth2PasswordRequestForm`** — класс-зависимость, упрощающий парсинг входящих данных формы, которые по спецификации обязаны содержать поля `username` и `password`.

**Анатомия JSON Web Token (JWT):** JWT представляет собой компактный и URL-безопасный способ передачи информации. Он состоит из трех частей: **Header** (алгоритм и тип), **Payload** (полезная нагрузка или "claims") и **Signature** (цифровая подпись). Подпись гарантирует целостность данных: сервер использует свой `SECRET_KEY`, чтобы убедиться, что токен не был изменен клиентом. В FastAPI для работы с JWT рекомендуется библиотека `PyJWT` или `python-jose`. Ключевым полем в `Payload` является `sub` (subject), где хранится уникальный идентификатор пользователя. Для безопасности токены всегда имеют время жизни `exp`, после которого они считаются недействительными.

**Стандарты хеширования паролей:** Хранение паролей в открытом виде категорически запрещено из-за рисков утечки базы данных. Вместо этого используются криптографические хеши. В 2026 году лучшей практикой считается алгоритм **Argon2id** (библиотека `argon2-cffi` или `pwdlib`), так как он наиболее устойчив к перебору на GPU по сравнению с `bcrypt`. Эти алгоритмы используют "соль" (Salt), чтобы сделать каждый хеш уникальным даже для одинаковых паролей, и "фактор медленности" для защиты от Brute-force атак.

#### Практическая реализация и синтаксис

Для реализации входа используется эндпоинт, принимающий форму и возвращающий JWT.

**Пример эндпоинта логина `/token`:**

```
from typing import Annotated
from fastapi import APIRouter, Depends, HTTPException, status
from fastapi.security import OAuth2PasswordRequestForm
# Предполагаются импорты схем и утилит из внутренних модулей
from .auth import create_access_token, authenticate_user

router = APIRouter(tags=["Authentication"])

@router.post("/token")
async def login_for_access_token(
    # FastAPI автоматически извлечет username и password из form-data
    form_data: Annotated[OAuth2PasswordRequestForm, Depends()]
):
    user = await authenticate_user(form_data.username, form_data.password)
    if not user:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Incorrect username or password",
            headers={"WWW-Authenticate": "Bearer"},
        )
    access_token = create_access_token(data={"sub": str(user.id)})
    return {"access_token": access_token, "token_type": "bearer"}
```

[OAuth2PasswordRequestForm](https://fastapi.tiangolo.com/tutorial/security/simple-oauth2/#oauth2passwordrequestform), [Response Model - Return Type](https://fastapi.tiangolo.com/tutorial/response-model/)

**Модуль работы с паролями (Argon2):**

```
from pwdlib import PasswordHash

# Использование рекомендованных настроек Argon2id
password_hash = PasswordHash.recommended()

def hash_password(password: str) -> str:
    return password_hash.hash(password)

def verify_password(plain_password: str, hashed_password: str) -> bool:
    return password_hash.verify(plain_password, hashed_password)
```

[Password Hashing best practices](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/#install-pwdlib)

**Генерация и декодирование JWT:**

```
from jose import JWT, JWTError
from datetime import datetime, timedelta, timezone

def create_access_token(data: dict, expires_delta: timedelta | None = None):
    to_encode = data.copy()
    expire = datetime.now(timezone.utc) + (expires_delta or timedelta(minutes=15))
    to_encode.update({"exp": expire})
    return JWT.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)

def verify_access_token(token: str, credentials_exception):
    try:
        payload = JWT.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        user_id: str = payload.get("sub")
        if user_id is None:
            raise credentials_exception
        return user_id
    except JWTError:
        raise credentials_exception
```

[Handle JWT tokens](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/#handle-jwt-tokens), [ExpiredSignatureError handling](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/#update-the-dependencies)

> [!warning] Актуализация синтаксиса 
> В старых версиях для генерации времени использовался метод `datetime.utcnow()`. В актуальном Python и FastAPI 2026 года следует использовать `datetime.now(timezone.utc)`, так как `utcnow` помечен как deprecated.

#### Глоссарий терминов

- **[OAuth2 Password Flow](https://fastapi.tiangolo.com/tutorial/security/first-steps/#the-password-flow)** — стандарт передачи учетных данных пользователя через форму для получения токена.
- **[`OAuth2PasswordBearer`](https://fastapi.tiangolo.com/tutorial/security/first-steps/#fastapis-oauth2passwordbearer)** — инструмент FastAPI для определения схемы безопасности в OpenAPI и извлечения токена из заголовков.
- **[JWT (JSON Web Token)](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/#about-jwt)** — стандарт токенов, содержащий подписанные данные в формате JSON.
- **[Access Token & Refresh Token](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/#handle-jwt-tokens)** — кратковременный токен для доступа к API и долгоживущий токен для обновления доступа без повторного ввода пароля.
- **[Argon2id / bcrypt](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/#install-pwdlib)** — современные адаптивные алгоритмы хеширования, устойчивые к аппаратным атакам.
- **Key Derivation Function (KDF)** — криптографический механизм, преобразующий пароль в секретный ключ.

#### Практический кейс: Построение безопасного сервиса аутентификации

**Сценарий:** Разработка финансового приложения. При регистрации пароль пользователя хешируется с использованием Argon2id и сохраняется в PostgreSQL (поле `password_hash`). При входе система проверяет пароль и выдает токен на 30 минут.

**Анализ безопасности:**

1. **Защита от timing attacks:** При поиске пользователя, если email не найден, система всё равно выполняет проверку пароля против "пустого" хеша. Это гарантирует, что время ответа сервера одинаково для существующих и несуществующих пользователей, предотвращая подбор логинов.
2. **Алгоритмическое замедление:** Использование Argon2id требует значительных вычислительных мощностей и памяти, что делает атаку перебора (Brute-force) экономически невыгодной для злоумышленника.
3. **Изоляция sensitive-данных:** Схема Pydantic `UserOut` исключает поле пароля из ответа API, предотвращая случайную утечку даже хешированных данных.

#### Вопросы и задания для самопроверки

1. **Вопрос:** В чем заключается преимущество алгоритма HS256 перед RS256 для внутренних микросервисов и почему RS256 предпочтительнее в публичных API?
    - _Ответ: HS256 использует один секретный ключ (симметричный), что проще в настройке. RS256 использует пару ключей (публичный/приватный), что позволяет сторонним сервисам проверять подпись токена, не зная секрета сервера._
2. **Задача:** Клиент передал токен, внутри `Payload` которого лежит поле `is_admin: true`. Безопасно ли доверять этому полю при выполнении административных действий?
    - _Решение: Да, если подпись JWT (`Signature`) верна и секретный ключ сервера не скомпрометирован, так как изменить Payload без нарушения подписи невозможно._
3. **Практическое задание:** Напишите функцию `generate_token_pair`, которая принимает `user_id` и возвращает словарь с двумя JWT: `access_token` (срок 15 мин) и `refresh_token` (срок 7 дней). Используйте Pydantic модели для конфигурации времени жизни.
