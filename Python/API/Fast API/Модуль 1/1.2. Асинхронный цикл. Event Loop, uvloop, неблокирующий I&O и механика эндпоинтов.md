#### Теоретический фундамент и архитектура

В основе высокой производительности FastAPI лежит асинхронная архитектура, управляемая циклом событий или `Event Loop`. `Event Loop` — это бесконечный цикл, который координирует выполнение асинхронных задач, переключаясь между ними в моменты ожидания ввода-вывода (I/O). Когда программа встречает ключевое слово `await`, `Event Loop` приостанавливает текущую сопрограмму (coroutine) и передает управление другим задачам, пока ожидаемый ресурс (база данных или внешний API) не вернет ответ. Это позволяет эффективно утилизировать ресурсы CPU, не допуская их простоя во время I/O-bound операций.

Для максимального ускорения этого процесса в продакшн-средах используется `uvloop` — высокопроизводительная замена стандартному циклу `asyncio`, написанная на языке C с использованием библиотеки `libuv`. `uvloop` делает `asyncio` значительно быстрее, приближая производительность Python к Node.js и Go.

**Механика выполнения эндпоинтов в FastAPI имеет критические различия:**

- **`async def` (Native Coroutines):** Эндпоинты, объявленные как `async def`, выполняются непосредственно в основном `Event Loop`. Это наиболее эффективный способ, но он требует использования только неблокирующих библиотек (например, `httpx` вместо `requests`). Если внутри такой функции вызвать блокирующий код, весь событийный цикл приложения остановится, и сервер перестанет отвечать на другие запросы.
- **`def` (Синхронные эндпоинты):** Если эндпоинт объявлен через обычный `def`, FastAPI автоматически запускает его в отдельном пуле потоков (`ThreadPoolExecutor` от Starlette). Это предотвращает блокировку `Event Loop`, позволяя другим запросам обрабатываться параллельно. Однако работа с потоками вносит накладные расходы (overhead) на переключение контекста ОС и потребляет больше памяти.

#### Практическая реализация и синтаксис

Правильный выбор между `async def` и `def` определяет стабильность системы под нагрузкой.

**Пример правильного использования типов функций:**

```python
import asyncio
import time
from fastapi import FastAPI

app = FastAPI()

# Правильно: async def для неблокирующего ожидания
@app.get("/async-task")
async def async_task():
    # Имитация I/O-bound операции (запрос к БД или API)
    await asyncio.sleep(1)
    return {"status": "success", "mode": "native coroutine"}

# Правильно: def для блокирующего I/O или CPU-heavy вычислений
@app.get("/sync-task")
def sync_task():
    # Имитация тяжелых вычислений или использования старой библиотеки
    time.sleep(1)
    return {"status": "success", "mode": "threadpool"}
```

**Наглядный пример фатальной ошибки:** Использование `time.sleep()` внутри `async def` заблокирует сервер для всех пользователей одновременно.

```python
# ОПАСНО: Этот эндпоинт остановит всё приложение на 5 секунд
@app.get("/block-everything")
async def block_all():
    import time
    time.sleep(5) # Event Loop полностью замирает
    return {"error": "loop was blocked"}

# ИСПРАВЛЕНИЕ: Если библиотека только синхронная, используйте обычный def
@app.get("/safe-sync")
def safe_sync():
    import time
    time.sleep(5) # FastAPI сам отправит это в поток, Loop будет свободен
    return {"info": "executed in threadpool"}
```

#### Глоссарий терминов

- **[Event Loop (Цикл событий)](https://fastapi.tiangolo.com/async/)** — центральный диспетчер задач в асинхронных приложениях, управляющий переключением между сопрограммами.
- **[Coroutine (Сопрограмма)](https://fastapi.tiangolo.com/async/)** — функция, объявленная как `async def`, выполнение которой может быть приостановлено и возобновлено.
- **[uvloop](https://fastapi.tiangolo.com/deployment/server-workers/)** — сторонняя библиотека для Python, заменяющая стандартный `asyncio.EventLoop` на более быстрый аналог на базе C.
- **[Non-blocking I/O](https://fastapi.tiangolo.com/async/)** — операции ввода-вывода, которые позволяют программе продолжать работу, не дожидаясь завершения передачи данных.
- **[ThreadPoolExecutor (Starlette threadpool)](https://fastapi.tiangolo.com/async/)** — механизм FastAPI для безопасного выполнения синхронного кода без блокировки основного цикла событий.
- **[Context Switching](https://fastapi.tiangolo.com/async/)** — процесс сохранения и восстановления состояния потока или процесса, создающий накладные расходы при большом количестве переключений.

#### Практический кейс: Диагностика и устранение блокировок Event Loop

**Сценарий:** Один из разработчиков внедрил в проект эндпоинт для обработки изображений, используя `async def` и синхронную библиотеку `Pillow`. Это привело к тому, что при загрузке фото у одного пользователя, API перестает отвечать всем остальным на несколько секунд.

**Диагностика:**

1. Включение режима отладки `asyncio` через переменную окружения `PYTHONASYNCIODEBUG=1` или в коде: `loop.set_debug(True)`.
2. В логах сервера появятся предупреждения: `Executing <Task...> took 2.500 seconds`, что указывает на блокировку цикла конкретной задачей.

**Пошаговое решение:**

1. **Идентификация:** Найти функцию, помеченную `async def`, которая выполняет тяжелые вычисления или блокирующий I/O.
2. **Рефакторинг:**
    - Самый простой способ: изменить декларацию на `def`, чтобы FastAPI автоматически вынес выполнение в `ThreadPoolExecutor`.
    - Продвинутый способ: использовать `anyio.to_thread.run_sync()` или `asyncio.to_thread()` внутри `async def`, чтобы вручную отправить блокирующую часть в пул потоков.
3. **Результат:** `Event Loop` освобождается для обработки входящих HTTP-запросов, а тяжелая задача выполняется параллельно в фоновом потоке.
