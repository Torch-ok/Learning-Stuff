#### Теоретический фундамент и архитектура

FastAPI не является изолированным монолитом; его архитектура — это синергия нескольких мощных инструментов. Фундаментально FastAPI выступает как высокоуровневая надстройка над `Starlette` и `Pydantic`.

- **Starlette:** Отвечает за всю «веб-часть»: маршрутизацию (routing), поддержку `WebSockets`, управление `Middleware`, сессии и асинхронную обработку HTTP-запросов.
- **Pydantic:** Служит ядром для валидации входящих данных и сериализации ответов. В FastAPI 2026 года стандартом является **Pydantic v2**, чье ядро `pydantic-core` написано на языке **Rust**. Это обеспечивает колоссальный прирост производительности при конвертации сложных JSON-структур в объекты Python и обратно.

**Продакшн ASGI-серверы:** Для работы приложения в асинхронной среде требуется сервер, реализующий спецификацию ASGI:

- **Uvicorn:** Традиционный выбор, использующий `uvloop` для ускорения событийного цикла и `httptools` для парсинга HTTP-трафика.
- **Granian:** Современный Rust-based сервер, который в 2026 году всё чаще выбирается для высоконагруженных систем. Его преимущество перед Uvicorn заключается в более эффективной утилизации многоядерных CPU и нативной реализации протоколов на Rust, что минимизирует задержки (latency).

**Менеджеры зависимостей:**

- **`uv` (Astral):** Сверхбыстрый инструмент на Rust, ставший в 2026 году стандартом. Он заменяет `pip`, `poetry` и `virtualenv`, позволяя устанавливать зависимости в 10-100 раз быстрее за счет глобального кэширования.
- **Poetry:** Декларативный менеджер, использующий `pyproject.toml` для описания проекта и `poetry.lock` для детерминированной фиксации версий библиотек.

#### Практическая реализация и синтаксис

Инициализация проекта и управление окружением с помощью `uv`:

```
# Инициализация нового проекта в текущей директории
uv init .

# Создание виртуального окружения и установка FastAPI с Uvicorn
uv add "fastapi[standard]"

# Добавление SQLAlchemy для работы с БД
uv add sqlalchemy
```

[Learn Fast API With This ONE Project / YouTube](https://www.youtube.com/watch?v=LearnFastAPI)

Пример современной конфигурации `pyproject.toml` для FastAPI проекта:

```
[project]
name = "fastapi-service"
version = "0.1.0"
description = "High performance production API"
dependencies = [
    "fastapi[standard]>=0.140.0",
    "pydantic>=2.10.0",
    "pydantic-settings>=2.4.0",
]

[project.scripts]
# Точка входа для запуска через CLI
start = "uvicorn main:app --host 0.0.0.0 --port 8000"
```

[Bigger Applications - Multiple Files](https://fastapi.tiangolo.com/tutorial/bigger-applications/#configure-the-entrypoint-in-pyproject-toml)

Команды запуска приложения в продакшн-окружении:

```
# Запуск через Uvicorn с тюнингом воркеров
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4 --loop uvloop

# Запуск через Granian (режим ASGI)
uv run granian main:app --interface asgi --workers 4 --threads 2 --backlog 2048
```

#### Глоссарий терминов

- **[Starlette](https://fastapi.tiangolo.com/tutorial/first-steps/#step-1-import-fastapi)** — ASGI тулкит, обеспечивающий базовую функциональность веб-фреймворка.
- **[Pydantic v2 (`pydantic-core`)](https://fastapi.tiangolo.com/tutorial/response-model/#response-model-return-type)** — высокопроизводительная библиотека валидации типов, работающая на Rust-ядре.
- **[Uvicorn](https://fastapi.tiangolo.com/tutorial/first-steps/#run-the-live-server)** — ASGI-сервер, используемый для выполнения асинхронного кода Python.
- **Granian** — современный Rust-сервер для протоколов ASGI/WSGI/RSGI.
- **[uv (Astral)](https://www.youtube.com/watch?v=LearnFastAPI)** — универсальный инструмент для управления Python-проектами и зависимостями.
- **[pyproject.toml](https://fastapi.tiangolo.com/tutorial/bigger-applications/#configure-the-entrypoint-in-pyproject-toml)** — основной файл конфигурации метаданных и зависимостей проекта.

#### Практический кейс: Сборка и оптимизация проекта на базе `uv` и Granian

**Сценарий:** Миграция микросервиса с `pip` и `requirements.txt` на `uv` и замена сервера с Uvicorn на Granian для снижения Latency.

**Анализ преимуществ:**

1. **Скорость сборки:** Использование `uv sync` сокращает время развертывания CI/CD пайплайна в несколько раз по сравнению с `pip install`.
2. **Производительность сервера:** Granian за счет Rust-реализации сетевого стека позволяет обрабатывать до 3000-5000 RPS (запросов в секунду) на стандартном железе с меньшим потреблением ресурсов CPU.

**Production-конфигурация запуска:** В файле `Dockerfile` или скрипте запуска используем:

```
# Оптимальный запуск Granian для ASGI
uv run granian main:app \
  --interface asgi \
  --workers 4 \
  --loop uvloop \
  --http h1 \
  --backlog 2048
```
