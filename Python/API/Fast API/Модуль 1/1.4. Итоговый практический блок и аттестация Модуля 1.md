#### Сводный академический глоссарий Модуля 1

| Термин                  | Описание                                                                                                                                                                                                      |
| :---------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| WSGI vs ASGI            | WSGI (PEP 3333) — синхронный интерфейс, блокирующий поток на каждый запрос; ASGI (PEP 3090) — асинхронный стандарт, позволяющий обрабатывать множество соединений (включая WebSockets) в одном цикле событий. |
| Event Loop / uvloop     | 'Event Loop' — ядро асинхронности, координирующее задачи; 'uvloop' — высокопроизводительная замена стандартного цикла на базе библиотеки 'libuv', написанная на C.                                            |
| Non-blocking I/O        | Модель ввода-вывода, при которой процессор не простаивает в ожидании ответа от внешнего ресурса (БД, API), а переключается на другие задачи.                                                                  |
| Native Coroutines       | Функции, объявленные как 'async def', выполняющиеся напрямую в 'Event Loop'; требуют использования только неблокирующих вызовов.                                                                              |
| External Threadpool     | Пул потоков ('ThreadPoolExecutor'), в котором FastAPI автоматически запускает синхронные эндпоинты ('def'), чтобы не блокировать основной 'Event Loop'.                                                       |
| Pydantic v2 Rust Engine | Новое поколение библиотеки валидации, где ядро 'pydantic-core' написано на Rust, что обеспечивает кратный прирост скорости сериализации.                                                                      |
| Starlette Toolkit       | Легковесный ASGI-фреймворк/тулкит, от которого FastAPI наследует механизмы маршрутизации, обработки исключений и middleware.                                                                                  |
| Granian / Uvicorn       | ASGI-серверы для запуска Python-приложений; Uvicorn является стандартом, а Granian — современным решением на Rust для максимальной производительности.                                                        |
| Package Manager 'uv'    | Современный и сверхбыстрый менеджер пакетов и зависимостей на Rust, заменяющий 'pip' и 'poetry'.                                                                                                              |

#### Сквозной практический кейс: Развертывание ASGI-сервера с uvloop и Granian

**Постановка задачи:** Разработать каркас микросервиса, использующий современные инструменты управления зависимостями ('uv'), обеспечивающий максимальную пропускную способность за счет 'uvloop' и готовый к высоконагруженному продакшну.

**Пошаговый алгоритм выполнения:**

1. **Инициализация проекта через 'uv':** Создайте директорию проекта и инициализируйте её. Это создаст 'pyproject.toml' для декларативного управления зависимостями.
    
    ```bash
    uv init .
    uv add "fastapi[standard]" httpx
    ```
    
2. **Написание точки входа 'main.py':** Реализуйте проверку типа эндпоинта. Используйте 'async def' для операций, поддерживающих 'await' (например, 'asyncio.sleep' или запросы через 'httpx'), чтобы избежать блокировки цикла событий.
    
    ```python
    from fastapi import FastAPI
    import asyncio
    
    app = FastAPI()
    
    @app.get("/health")
    async def health_check():
        # Имитация неблокирующего I/O
        await asyncio.sleep(0.1)
        return {"status": "ok", "loop": "active"}
    ```
    
3. **Конфигурация запуска:** Для 'Uvicorn' используйте флаги '--loop uvloop' и '--http httptools' для достижения максимальной производительности. В многоядерных системах настройте количество воркеров ('--workers').
    
    ```bash
    # Запуск Uvicorn (стандарт 2026)
    uv run uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4 --loop uvloop --http httptools
    ```
    
4. **Нагрузочное тестирование:** Используйте инструменты командной строки для симуляции конкурентных запросов и проверки того, как 'Event Loop' справляется с нагрузкой без создания очереди.
    
    ```bash
    # Пример тестирования через curl или специализированные утилиты
    curl -I http://127.0.0.1:8000/health
    ```
    
5. **Анализ метрик:** Отслеживайте логи сервера. Если 'Event Loop' блокируется, сервер 'Uvicorn' или 'Granian' сообщит о задержках в обработке задач.
    

#### Комплексный контрольный тест для самопроверки

1. **Вопрос:** Какой из перечисленных эндпоинтов полностью остановит обработку запросов для всех пользователей на время своего выполнения?
    
    - A) 'def' с 'time.sleep(10)'
    - B) 'async def' с 'await asyncio.sleep(10)'
    - C) 'async def' с 'time.sleep(10)'
    - _Ответ: С. Блокирующий вызов внутри 'async def' останавливает весь 'Event Loop'._
2. **Вопрос:** В чем фундаментальное преимущество ASGI перед WSGI при работе с 'C10K' (10 000 одновременных соединений)?
    
    - _Ответ: ASGI использует неблокирующий ввод-вывод и 'Event Loop', позволяя одному процессу управлять тысячами соединений, в то время как WSGI требует создания отдельного потока/процесса на каждое соединение._
3. **Практическое задание:** Найдите ошибку в коде и исправьте её, чтобы приложение не блокировалось:
    
    ```
    @app.get("/data")
    async def get_external_data():
        import requests
        response = requests.get("https://api.example.com") # Ошибка здесь
        return response.json()
    ```
    
    _Подсказка: замените синхронную библиотеку 'requests' на асинхронную (например, 'httpx') и добавьте 'await'._
    
4. **Задача:** Сервер имеет 4 физических ядра. Какую команду запуска 'Uvicorn' вы предложите для оптимальной утилизации ресурсов в продакшне?
    
    - _Ответ: Использовать '--workers 4' (или формулу 2N+1) и '--loop uvloop'._
5. **Вопрос:** Как Pydantic v2 влияет на производительность ASGI-приложения FastAPI?
    
    - _Ответ: Благодаря 'pydantic-core' на Rust, процесс превращения JSON в объекты Python (и обратно) происходит на низком уровне, что минимизирует 'CPU-bound' нагрузку на 'Event Loop'._
